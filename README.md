# CloudVault
Secure Cloud Storage System

-> Developed a C++ cloud storage application using the AWS SDK for C++ and Amazon S3 to support file upload, download, listing, and deletion operations.
-> Implemented SHA-256 hash verification to detect duplicate files and prevent redundant uploads.
-> Configured AWS IAM users and access permissions to manage authentication and control access to cloud storage resources.
-> Integrated Amazon CloudWatch Logs to record S3 operations for activity monitoring, with Docker Desktop and LocalStack for local AWS service emulation and CMake for build management.
